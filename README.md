# Car Rental Reservation and Return System

## Project Description:

The Car Rental Reservation and Return System is a Database Management System (DBMS) project designed to simplify and manage the process of renting and returning cars. The system allows users to view available cars, make rental reservations, manage booking details, and record car returns efficiently.

This project maintains organized records of cars, customers, reservations, rental details, and payments in a structured database. It helps reduce manual work, avoid duplicate bookings, and improve the efficiency of car rental operations.
